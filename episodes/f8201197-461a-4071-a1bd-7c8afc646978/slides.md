# 3.9 折的真相

<div class="text-left">

外界听到"3.9 折"，以为是把 Seedance 等模型 API 打折转卖、用激进定价抢市场。

实际上，3.9 折是**月费折成年包的折扣**——按月付费的价格折算成全年，差价就是那个"折"。

定价不是拍脑袋，而是一条被测算过的链条：

<div class="grid grid-cols-2 gap-3 mt-3 text-sm leading-relaxed">

<div class="p-3 rounded bg-blue-50 border-l-4 border-blue-500">成本 → 积分 → 价格带 → 消耗率 × 续费率 → LTV</div>

<div class="p-3 rounded bg-green-50 border-l-4 border-green-500">检验结果：公司现金流转正（从 5 月开始）</div>

</div>

</div>

# 健身房模式：年卡赌的是什么

<div class="mt-6 p-6 text-lg italic border-l-4 border-blue-500 bg-blue-50 bg-opacity-20 text-left">

"本质上就是一个健身房模式嘛，它赌的是你办了年卡之后，你这些人不会每个月或者每天都来。靠的是绝大多数用户全年用不完这个假设。"

</div>

<div class="grid grid-cols-3 gap-3 mt-6 text-sm leading-relaxed text-left">

<div class="p-3 rounded bg-blue-50 border-l-4 border-blue-500">

### 为什么赌得赢
工具产品是低频使用的周活产品（作者概括：用户不会像刷短视频一样每天打开），"用不完"大概率成立。

<div class="p-3 rounded bg-green-50 border-l-4 border-green-500">

### 对用户

</div>

<div class="p-3 rounded bg-orange-50 border-l-4 border-orange-500">

### 对公司
提前锁定续费与现金流，摊薄模型调用成本，规模越大单位成本越低。

</div>

# 三种商业模式的命题

<div class="text-left">

LibTV 的定价争议背后，是 AI 应用到底怎么收费的问题。陈冕拆成三种：

<div class="grid grid-cols-3 gap-3 mt-4 text-sm leading-relaxed">

<div class="p-3 rounded bg-blue-50 border-l-4 border-blue-500">

### 订阅制
按时间收费。用户付固定月费/年费，不问用量。

</div>

<div class="p-3 rounded bg-yellow-50 border-l-4 border-yellow-500">

### 纯 Token 消耗
按用量收费。用多少付多少，用户对成本敏感。

</div>

<div class="p-3 rounded bg-green-50 border-l-4 border-green-500">

### 会员卡 + usage
年卡锁定续费，积分按量消耗——LibTV 3.9 折年包的做法。

</div>

</div>

<div class="mt-4 p-4 rounded bg-purple-50 border-l-4 border-purple-500 text-sm leading-relaxed">

### 配套的毛利观

"我们并不追求低毛利，而是阶段性的低毛利。"——"你追求很高的毛利，你就会压制需求。"
