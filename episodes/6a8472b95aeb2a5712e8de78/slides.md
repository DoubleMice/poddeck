# 论文思路：一个 projection 两件事

<div class="text-sm leading-relaxed space-y-2 mt-2">

<div class="p-2 rounded bg-blue-50 border-l-4 border-blue-500">
<strong>起点是别人的思路</strong><br/>
<span class="opacity-70">框架来自 value of visual learning：把第一层 attention 的 value 加到之后几层里做残差</span>
</div>

<div class="p-2 rounded bg-green-50 border-l-4 border-green-500">
<strong>他的发现</strong><br/>
<span class="opacity-70">在残差上用 RMS Norm，可以把 value 延展到 key 和 query 上，"最后效果更好"</span>
</div>

<div class="p-2 rounded bg-orange-50 border-l-4 border-orange-500">
<strong>关键的一步</strong><br/>
<span class="opacity-70">第一层的 value 有两件事：这一层自己用 + 加到之后几层做残差。"把第一层的 attention projection 宽度乘二，然后呢再那个切一半，一半用于这一层，另一半用于之后残差"</span>
</div>

<div class="p-2 rounded bg-purple-50 border-l-4 border-purple-500">
<strong>不是刻意选的</strong><br/>
<span class="opacity-70">"我也不是故意去选是做 attention 还是做 visual……我也是机缘巧合才在这个上面有了一些进展。"</span>
</div>

</div>

# 直觉与 aha moment：QKV 到底是什么

<div class="text-sm leading-relaxed space-y-3 mt-4">

<div class="p-4 rounded bg-blue-50 border-l-4 border-blue-500">
<div class="italic">

# AGI 的想象：像跟外星人交流

<div class="mt-4 space-y-3 text-sm leading-relaxed">

<div class="p-4 rounded bg-blue-50 border-l-4 border-blue-500">
<div class="italic">
"我觉得最酷的一件事情就是24小时你能感觉跟你一样智商或者比你更聪明、更快的一个生物交流吧。就好像就是跟外星人交流。"
</div>
<div class="text-xs opacity-50 mt-1 not-italic">— 苏庭浩 · 最不可思议的一件事</div>
</div>

<div class="grid grid-cols-2 gap-3">

<div class="p-3 rounded bg-green-50 border-l-4 border-green-500">
<strong>AGI 的定义</strong><br/>
<span class="opacity-70">现在的模型"有时候有一点，比如1%，0.1%的时候能看出它其实只是一个预测下一个token的一个model"。真 AGI 是"没有任何时候你会觉得它只是一个预测下一个token的，而是逻辑性很强，不会犯那么多低级的错误"</span>
</div>

<div class="p-3 rounded bg-purple-50 border-l-4 border-purple-500">
<strong>给自己造身体</strong><br/>
<span class="opacity-70">AGI 能做所有人类能做的事：控制电脑、控制其他 AI，"那时候它可以自己研究那个具身智能，给自己造一个身体"——甚至可能是六只手臂、一条腿、"没有大脑"的机器人</span>
</div>

</div>

<div class="p-3 rounded bg-orange-50 border-l-4 border-orange-500">
<strong>最像人的地方</strong><br/>
<span class="opacity-70">"有时候AI也会犯一些低级的错误，人类有时候也会犯低级的错误……所以我觉得最像人类的就是犯一些低级错误。"——他被 trick 过的问题，AI 也被 trick 到，"发现AI也挺像人类了"</span>
</div>

</div>
